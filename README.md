# centel.app — วางแผนจ่ายบิล

เว็บแอปสำหรับวางแผนการจ่ายค่าบัตรเครดิต ค่าน้ำ ค่าไฟ และบิลรายเดือนอื่นๆ ออกแบบสำหรับ iPhone
ติดตั้งลงหน้าจอโฮมได้ (PWA) ใช้งานออฟไลน์ได้ และเก็บข้อมูลไว้ในเครื่องเท่านั้น

## ความสามารถ

- เพิ่มบิลแบบ **ทุกเดือน**, **ผ่อนเป็นงวด** (แสดงงวดที่ x/y) หรือ **ครั้งเดียว**
- บิล **ยอดไม่แน่นอน** (บัตรเครดิต ค่าน้ำ ค่าไฟ) กรอกยอดจริงได้ในแต่ละเดือน
- หน้า **เดือนนี้**: ยอดรวม จ่ายแล้ว คงเหลือ, ยอดที่ต้องเตรียมช่วงวันที่ 1–15 และ 16–สิ้นเดือน, แจ้งเตือนบิลเลยกำหนด/ใกล้ครบกำหนด
- แตะวงกลมเพื่อทำเครื่องหมาย **จ่ายแล้ว**
- **ปฏิทิน** รายเดือนแสดงสถานะบิลแต่ละวัน
- **เตือนผ่านแอปปฏิทิน iPhone**: สร้างไฟล์ .ics พร้อมเสียงเตือนล่วงหน้า
- ตัวเลขแจ้งเตือนบนไอคอนแอป (iOS 16.4+ เมื่อติดตั้งที่หน้าจอโฮม)
- สำรอง/นำเข้าข้อมูลเป็น JSON, รองรับโหมดมืด

## ใช้งานบน iPhone

1. เปิดเว็บด้วย Safari
2. แตะปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## Deploy

ไฟล์ทั้งหมดเป็น static (ไม่มีขั้นตอน build) — `.github/workflows/pages.yml` จะ deploy ขึ้น GitHub Pages
เมื่อ push เข้า `main` (ต้องเปิด Settings → Pages → Source: **GitHub Actions** ก่อน)

ทดสอบในเครื่อง: `npx http-server .` แล้วเปิด http://localhost:8080

## โดเมน centel.app (Namecheap)

ไฟล์ `CNAME` ระบุโดเมน `centel.app` ไว้ ตั้งค่า DNS ใน Namecheap → Domain List → Manage → **Advanced DNS**
(ลบ record เดิมของ Namecheap เช่น parking page / URL Redirect ก่อน):

| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| AAAA | @ | 2606:50c0:8000::153 |
| AAAA | @ | 2606:50c0:8001::153 |
| AAAA | @ | 2606:50c0:8002::153 |
| AAAA | @ | 2606:50c0:8003::153 |
| CNAME | www | thitiwutchm.github.io. |

จากนั้นที่ GitHub → Settings → Pages → Custom domain ใส่ `centel.app` → Save แล้วเปิด **Enforce HTTPS**
(โดเมน .app บังคับ HTTPS เสมอ เว็บจะเปิดได้หลังใบรับรองออกเสร็จ ปกติไม่เกิน 1 ชั่วโมง)
