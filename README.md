# centel.app — วางแผนจ่ายบิล

เว็บแอปสำหรับวางแผนการจ่ายค่าบัตรเครดิต ค่าน้ำ ค่าไฟ และบิลรายเดือนอื่นๆ ออกแบบสำหรับ iPhone
ติดตั้งลงหน้าจอโฮมได้ (PWA) ใช้งานออฟไลน์ได้ และเก็บข้อมูลไว้ในเครื่องเท่านั้น

## ความสามารถ

- เพิ่มบิลแบบ **ทุกเดือน**, **ผ่อนเป็นงวด** (แสดงงวดที่ x/y) หรือ **ครั้งเดียว**
- บิล **ยอดไม่แน่นอน** (บัตรเครดิต ค่าน้ำ ค่าไฟ) กรอกยอดจริงได้ในแต่ละเดือน
- หน้า **เดือนนี้**: ยอดรวม จ่ายแล้ว คงเหลือ, ยอดที่ต้องเตรียมช่วงวันที่ 1–15 และ 16–สิ้นเดือน, แจ้งเตือนบิลเลยกำหนด/ใกล้ครบกำหนด
- แตะวงกลมเพื่อทำเครื่องหมาย **จ่ายแล้ว**
- **ปฏิทิน** รายเดือนแสดงสถานะบิลแต่ละวัน
- **เตือนผ่านแอปปฏิทิน iPhone**: สร้างไฟล์ .ics พร้อมเสียงเตือนล่วงหน้า
- ตัวเลขแจ้งเตือนบนไอคอนแอป (iOS 16.4+ เมื่อติดตั้งที่หน้าจอโฮม)
- สำรอง/นำเข้าข้อมูลเป็น JSON, รองรับโหมดมืด

## ใช้งานบน iPhone

1. เปิดเว็บด้วย Safari
2. แตะปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## Deploy

ไฟล์ทั้งหมดเป็น static (ไม่มีขั้นตอน build)

- **Railway** (โดเมน centel.app): Railway build จาก `Dockerfile` ซึ่งเสิร์ฟไฟล์ด้วย Caddy ตาม `Caddyfile`
  (ฟังที่ `$PORT`) และ deploy ใหม่อัตโนมัติเมื่อ push เข้า `main`
- **GitHub Pages** (สำรอง): `.github/workflows/pages.yml` จะ deploy เมื่อ push เข้า `main`

ทดสอบในเครื่อง: `npx http-server .` แล้วเปิด http://localhost:8080

## ThemeA (ดีไซน์สไตล์ Apple)

`themea/` คือหน้าตาแบบ Apple ของแอปเดียวกัน เปิดที่ `/themea/` ใช้ข้อมูลชุดเดียวกับหน้าหลัก (localStorage `billplanner.v1`)
แนวทาง: สีระบบ iOS, หัวข้อใหญ่ที่ย่อเข้าแถบโปร่งแสง, หน้าต่างล่างลากปิดได้ด้วยแอนิเมชันสปริง, รองรับลดการเคลื่อนไหว/ความโปร่งใส

## ThemeB (ดีไซน์ทางเลือก)

`themeb/` คือหน้าตาแบบที่สองของแอปเดียวกัน เปิดที่ `/themeb/` ใช้ข้อมูลชุดเดียวกับหน้าหลัก (localStorage `billplanner.v1`)
แนวทาง: สูตร "raycast" จาก web-design-engineer skill — พื้นเทาเข้ม การ์ดกระจกโปร่งแสงบนแสงไล่สีอุ่น สีแดง #FF6363 เฉพาะปุ่มสำคัญ จุดสีประจำหมวด ชิปตัวเลขแบบปุ่มคีย์บอร์ด
ฟอนต์ IBM Plex Sans Thai, Inter Tight, JetBrains Mono ฝังไว้ใน `themeb/fonts/` (OFL)
