ติดตั้ง Centel

แอป iPhone สำหรับเครื่องที่ลงทะเบียนไว้

ติดตั้งแอป
  1. เปิดหน้านี้ใน Safari แล้วกดปุ่มด้านบน กด ติดตั้ง
  2. รอไอคอน Centel บนหน้าโฮมโหลดจนเสร็จ
  3. ครั้งแรก ถ้าเปิดไม่ได้ ให้ไปที่ ตั้งค่า > ความเป็นส่วนตัวและความปลอดภัย > โหมดนักพัฒนา เปิดแล้วรีสตาร์ท

ยังไม่มีแอปให้ติดตั้ง รอ build แรกก่อนนะ

ติดตั้งแล้วขึ้นว่า "ไม่สามารถติดตั้งได้" แปลว่าเครื่องนี้ยังไม่ได้ลงทะเบียน ขอรหัสเครื่องที่ centel.app/udid ก่อน
